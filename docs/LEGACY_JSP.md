# JSP 页面与登录动画练习

一个早期 Web 页面学习项目，包含 JSP 管理界面原型，以及使用 HTML、CSS 和原生 JavaScript 编写的登录 / 注册切换动画。

当前代码用于记录页面布局与导航练习；业务页面多为占位，运行环境尚未验证。它没有实现完整的数据管理或用户认证流程，也没有经验证的在线演示。

## 技术与练习内容

- **JSP**：页面指令、字符编码声明和页面组织。
- **HTML / CSS**：表单、菜单、按钮、布局和过渡动画。
- **原生 JavaScript**：按钮事件、CSS class 切换和页面跳转。
- 当前仓库未包含 Java 后端实现、数据库脚本或依赖管理配置。

## 当前实现范围

以下状态依据源码检查，未经过部署或浏览器运行验证。

| 部分 | 代码中已有内容 | 当前边界 |
| --- | --- | --- |
| 登录 / 注册界面 | 双面板表单、切换按钮和 CSS 动画 | 表单提交被 `preventDefault()` 阻止，没有认证或注册逻辑 |
| 主菜单 | 数据管理、结果查询、个人中心入口 | 通过按钮跳转到对应 JSP 页面 |

| 个人中心 | 修改密码、退出登录、返回按钮 | 修改密码未实现；退出登录仅跳转页面 |

## 运行与部署状态

**尚未验证可复现的运行环境。** 仓库没有提供 JDK、JSP 容器版本、构建文件或部署配置，因此这里不提供未经验证的启动命令。

预览含 JSP 指令的页面需要支持 JSP 的运行环境；直接把 `.jsp` 文件作为普通静态文件打开，无法验证其服务器处理行为。后续若补充运行说明，应记录实际验证过的环境、部署过程和截图。

### 关于 GitHub Pages

GitHub 官方将 Pages 定义为 HTML、CSS、JavaScript 的静态站点托管服务，并说明其不支持服务器端语言。因此，Pages 无法直接执行本仓库的 JSP 页面；仓库名称本身也不能证明页面已经部署成功。

参考官方文档：[What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages) · [Creating a GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。
