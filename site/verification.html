FracLogGPT: A Multimodal Large Language Model for Fracture Interpretation in Imaging Logging

Hushuang Shen, Ang Li, Liyan Zhang, Xiangxiang Liu. Electronics, 15(1), 127, 2026。第一作者，已发表；通讯作者为 Ang Li。正式引用采用 2026 卷年，在线发表日期为 2025-12-26。

论文的作者贡献声明列明 Hushuang Shen 负责方法设计、软件实现、实验分析、研究执行与初稿撰写；研究构思、验证、数据整理和可视化包含共同作者参与。

论文报告基于 Qwen2.5-VL-7B 的 DAPT、LoRA SFT 与 DPO 三阶段实验，独立测试集的裂缝计数分类 Count-F1 为 0.70。该数值属于论文中的实验结果，不能视为 FracLogGPT-Lite 公开精简实现或 4B 配置已复现的效果。

DOI：10.3390/electronics15010127 · 出版商页面 · 版本与发表日期

Two-Stage Recruitment Text Labeling via Lexicon-Guided Routing and Retrieval-Augmented Large Language Models

Hushuang Shen, Yuan Wang. Journal of Visualized Experiments, (231), e70153, 2026。第一作者，已发表；通讯作者为 Yuan Wang。发表日期为 2026-05-08。

论文研究包含词表引导分流、向量检索与 RAG 推理。在 3,000 条人工核验的 AI／环保／其他三分类基准上，论文报告准确率为 98.47%，并用于约 693 万条招聘信息的语料标注。该结果受三标签任务与论文评测协议约束，不直接代表更细岗位体系或其他语料的分类效果。

公开代码展示 TF-IDF／随机森林、可选 BERT 路径与 HTTP 协议适配等精简基线，没有发布完整 RAG 知识库、原始招聘语料或整套论文实验。论文中的 RAG 方法与公开基线的实现范围应分别阅读。

Persistent Retrieval in Hierarchical Memory Systems for Long-Context Agents: A Controlled Evaluation

Hushuang Shen, Yuan Wang. IEEE International Conference on Systems, Man, and Cybernetics (SMC), 2026。共同一作，Hushuang Shen 作者首位；论文首页明确两位作者贡献相同，通讯作者为 Yuan Wang。

留存的 2026-06-21 录用函确认 accepted for presentation。官方议程列有同题、同作者论文，安排为 2026-10-06 14:30–14:45，TuA16.5。目前保留“已录用”状态，尚无已核实的正式出版 DOI；议程安排本身也不用于证明作者实际出席。

研究在固定模型、解码、提示骨架、检索评分与预算策略下比较五种记忆配置。论文与会议议程摘要报告：在证据稀缺协议下，L0+L2 相对当前轮组织基线在 LoCoMo、LongBench v2、LongMemEval 的绝对分值增益分别为 0.0628、0.1233、0.1220，平均为 0.103；叠加 L1／L3 未继续改善该协议下的最佳结果。

Implementation Scope

FracLogGPT-Lite

提供阶段编排、预测恢复与视觉对比解码代码；公开单元测试没有执行完整模型训练或实测模型推理。仓库内论文基线字段不作为已复现的个人实验结果，4B 与 7B 模型也没有据此进行同测试集效果比较。

MemLab

上下文预算使用字符长度启发式估算，不保证 tokenizer 的精确 token 数。离线哈希嵌入用于流程验证，不是训练后的语义向量。Redis、PostgreSQL、Qdrant 及外部 API 的端到端集成没有通过这批离线测试验证。

招聘文本三分类

TF-IDF／随机森林用于基线流程；BERT 是可选路径，实际训练、模型下载与外部 HTTP 服务没有在此次验证中运行。合成示例不用于说明真实业务规模或泛化效果；HTTP 协议适配没有实现 RAG。
